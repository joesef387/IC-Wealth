# IC Wealth

This repository contains a static demo site. It uses sample portfolio data and does not connect to financial accounts.

## GitHub Pages

The workflow in `.github/workflows/pages.yml` enables and deploys the site from the `main` branch. After a successful deployment, the site will be available at:

`https://joesef387.github.io/IC-Wealth/`

Do not add real personal information, account details, or credentials to this public demo.
